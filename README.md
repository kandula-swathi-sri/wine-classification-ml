# Wine Classification using Machine Learning

This project classifies wine samples into three different categories using machine learning algorithms.

## Models Used

- Logistic Regression
- K-Nearest Neighbors
- Random Forest

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Joblib

## Project Workflow

1. Load the Wine dataset from Scikit-learn
2. Check missing values
3. Split the data into training and testing sets
4. Train multiple classification models
5. Evaluate models using accuracy, precision, recall and F1-score
6. Select and save the best model
7. Generate a confusion matrix
8. Analyze feature importance
